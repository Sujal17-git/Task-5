# Task-5
Task 5  AL &amp; ML Internship By Elevate Labs

Software Requirement : Jupiter Notebook
Tools : Pandas, Matplotlib, Seaborn, Sklearn
Dataset Heart Disease Dataset

1. Train a Decision Tree Classifier and visualize the tree
A Decision Tree classifier was trained on the Heart Disease Dataset to predict the presence of heart disease. The trained tree was visualized to understand the decision-making process based on feature splits.

2. Analyze overfitting and control tree depth
To detect and reduce overfitting, the tree's depth was varied, and its impact on training and testing accuracy was plotted. This helped identify the optimal tree depth for better generalization.

3. Train a Random Forest and compare accuracy
A Random Forest classifier was trained to improve performance by combining multiple trees. Its accuracy was compared to the single Decision Tree, showing better results due to ensemble learning.

4. Interpret feature importances
The Random Forest model's feature importances were extracted to identify which features contributed most to the prediction. A bar chart was used to visualize and rank these features.

5. Evaluate using cross-validation
Both models were evaluated using 10-fold cross-validation to measure their stability and general performance. The Random Forest consistently showed higher average accuracy across folds.
